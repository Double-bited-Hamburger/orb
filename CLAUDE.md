# Orb — animated shader orb + liquid-glass clock

A fullscreen "screensaver" app for a second monitor, inspired by the Logitech G HUB update animation:
a glowing, rippling particle orb on a **true-black (AMOLED) background**, with a liquid-glass clock.
The owner uses it on a second monitor while charging, watching videos or studying, so **visual quality
comes first** and GPU usage may be high. Keep the AMOLED rule: everything that isn't lit must be pure black.

## Files

| Path | What |

## Building

Compiler: WinLibs MinGW-w64 GCC, installed via `winget install BrechtSanders.WinLibs.POSIX.UCRT`.
It is **not on PATH in agent shells**, so prepend it first:

```powershell
$env:Path = "$env:LOCALAPPDATA\Microsoft\WinGet\Packages\BrechtSanders.WinLibs.POSIX.UCRT_Microsoft.Winget.Source_8wekyb3d8bbwe\mingw64\bin;$env:Path"
cmd /c native\build.bat            # -> native\Orb.exe
cmd /c "native\build.bat OrbTest.exe"   # build beside it while the user's Orb.exe is running
```

- If `Orb.exe` is locked, the user has it open. **Don't kill it**: build `OrbTest.exe`, test that, and ask the user to close theirs before swapping.
- Links: `d3d11 dxgi ole32 gdi32 user32 comctl32 comdlg32 dwmapi winmm`, `-static -s -mwindows`.
- **Manifest trick:** GCC always links its own `default-manifest.o`, which conflicts with ours ("multiple non-default manifests"). `build.bat` creates an empty `build\default-manifest.o` and passes `-Bbuild\` so ours is the only manifest.

## Architecture (`orb.cpp`)

**Rendering: two passes per frame, D3D11, flip-model swap chain, vsync.**
1. `psScene` renders the scene into an offscreen texture at **render scale** (the `Render res.` slider).
2. `psComp` draws at full resolution: it upscales the scene and draws the liquid-glass panel and clock text.
- Fullscreen quad from `SV_VertexID` (no vertex buffers). Constant buffers: `Orb` (b0) and `Comp` (b1). The C++ structs `OrbCB` and `CompCB` must match the HLSL layout exactly (16-byte rows).
- `psScene`'s `fc` is `gl_FragCoord`-style (bottom-left origin); `p` is in screen-height units, centred, minus the drift offset.

**Forms** (`S.form`, keys 1–7): 0 Orb, 1 Blob, 2 Ring, 3 Cube, 4 Crystal, 5 Aurora, 6 Nebula.
- 0–4 are **raymarched SDFs** (`sdShape`). Camera at z=4, `rd = normalize(uv*0.258, -1)`, so a unit sphere fills `uSize`. Marching only happens inside a bounding sphere of radius 2.2; outside it, `dmin` is estimated for the halo.
- The surface pattern is the original orb's: interference of 4 travelling waves along `normalize(objectSpacePoint)`, domain-warped by noise, plus a particle stipple anchored to the 3D surface. Edges fade by `n·v` (the fuzzy silhouette).
- 3D→3D switches are a **true SDF morph** (`lerp` of distances). Anything involving Aurora/Nebula **cross-fades**.
- Morph state lives in C++: `g_formA`, `g_formB`, `g_morph`, `setForm(f, seconds)`. Auto-morph cycles through forms 0–4.

**Shader compile-time pitfalls** (fxc via `d3dcompiler_47.dll`). The first 3D version hung for over 20 s:
- Each big function (`orb3D`, `aurora`, `nebula`) must have **exactly one call site** in `psScene`. The weights are computed first, then each is called once.
- `calcNormal` uses a real `[loop]` over the 4 tetrahedron taps; the blob loop is `[loop]` too. Don't `[unroll]` anything that calls `map()`.
- Optimization flags are 0 (default level).
- Compiled blobs are **cached** in `%APPDATA%\Orb\shaders.bin`, keyed by an FNV-1a hash of the HLSL source. The first launch after a shader change takes ~3 s; later launches take ~0.5 s.

**Liquid glass** (`psComp`, style 2):
- Rounded-box SDF panel.
- Rim-weighted refraction: the background is pulled inward near the edges.
- 32-tap golden-angle frosted blur.
- RGB chromatic split along the rim.
- Saturation boost and a faint milky body (so it still reads on pure black).
- Top sheen and a rim highlight (key light top-left, weaker back light).
- Drop shadow.
- Text drawn on top with a blurred shadow.

**Clock text:** rendered with GDI into a BGRA texture. Each element goes in its own colour channel so it can get its own opacity: big digits in R (100%), seconds and AM/PM in G (60%), date in B (72%). The texture is rebuilt only when the text changes. Fonts are Segoe UI Variable Display/Text, falling back to Segoe UI.

**Audio** (`audioUpdate`): WASAPI **loopback** of the default output device, polled once per frame (no thread).
- It computes RMS plus a ~120 Hz low-passed bass level, with attack/release envelopes and an **auto-gain** that follows the recent peak.
- Outputs `A.level` and `A.bass` (0..~1 × Sensitivity). These drive: size pulse, faster ripples (`simT`), brightness, halo and wobble.
- It reconnects after device changes. Nothing is stored.

**Other details:**
- Anti-burn-in drift slowly moves both the orb and the clock.
- Color cycle hue-rotates the 4 palette colours on the CPU.
- Stars are two parallax layers of hashed cells, hidden behind lit areas.
- Shader time is wrapped with `fmod(simT, 20000)` to keep float precision over long runs.
- A lost GPU device (driver update, GPU switch) is handled by recreating D3D.
- The cursor hides after 2.5 s without movement.

**Settings window** (custom dark Win32 UI): three columns.
- Owner-drawn buttons for presets, colour swatches (open ChooseColor), forms, clock style, toggles, and cycling buttons (FPS cap, clock position).
- Trackbars map 0..1000 to each param's range (the `PD[]` table). Adding a slider means adding an enum entry, a `PD[]` row and a `sliderRow(...)` call in `buildSettings()`.
- It rebuilds itself on `WM_DPICHANGED`.
- Static labels need `SS_NOPREFIX`, otherwise `&` disappears.

## Controls

`H` / right-click: settings · `F` / `F11` / `Alt+Enter` / double-click: fullscreen (borderless, on the window's current monitor) ·
`1–7`: form · `M`: auto-morph · `C`: clock style (Off/Minimal/Glass) · `A`: react to sound · `Space`: pause ·
`Esc`: close settings, or leave fullscreen.

## Settings storage

- `%APPDATA%\Orb\orb.ini`, saved about once a second after a change and on exit. Keys under `[orb]` match `PD[].key`, plus `c0..c3` (hex), `drift automorph h24 seconds date audio fps form clockstyle clockpos`.
- `[window]` keeps the last normal position and the fullscreen flag, so the app reopens fullscreen on the same monitor. The position is only restored if it is still on a connected monitor.
- The **`ORB_INI` env var** overrides the ini path. `tools/shot.ps1` uses it so tests never touch the user's real settings.
- A missing ini means first run, so the settings panel opens automatically.

## Measured facts / decisions (don't re-litigate)

- **D3D11 over OpenGL:** the OpenGL build used 117 MB of private memory; D3D11 uses ~56–62 MB, of which ~53 MB is the GPU driver baseline. Assembly or another language would not help, because the cost is the driver.
- **GPU choice:** the laptop has an AMD Radeon 780M iGPU and an RTX 5060. Forcing the iGPU (`DXGI_GPU_PREFERENCE_MINIMUM_POWER`) loaded **both** drivers (92 MB). We use the default adapter, and the user can choose a GPU per app in Windows Settings → Display → Graphics.
- **Wide format strings:** with MinGW UCRT, `swprintf` needs `%ls` for `wchar_t*`. `%s` printed only the first character.
- **Measured CPU use:** ~4–7% of one core at 60 fps.

## Testing

```powershell
.\native\tools\shot.ps1 -Name ring_glass -Orb @{form=2; clockstyle=2; drift=0; seconds=1}
.\native\tools\shot.ps1 -Name panel -Orb @{form=0} -Settings
.\native\tools\shot.ps1 -Name morph -Orb @{form=0; automorph=1; morphsec=10} -Wait 11
```

Then look at `native/tools/out/*.png`. Use `drift=0` for stable framing.
The script makes Orb topmost before capturing, and refuses to save if another window covers it.
Without that, Windows sometimes kept another app in front and the screenshot captured private content.
**Always look at a screenshot before committing or publishing it.**

Checked so far:
- Every form, both clock styles, several positions, the morph, the settings panel, and render scale.
- The sound connects to the audio output ("Sound: listening").

Not yet checked:
- How the sound reaction looks while audio is actually playing.
- Fullscreen on the second monitor.
